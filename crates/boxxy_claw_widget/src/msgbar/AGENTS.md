# Msgbar Module (`boxxy_claw_widget::msgbar`)

## History
Formerly the standalone `boxxy-msgbar` crate. Folded into `boxxy-claw-widget` during the phase-2 extraction because the merged msgbar has exactly one consumer (the claw drawer) and a separate crate boundary no longer earned its keep.

## Responsibility
Provides `MsgBarComponent` — the input bar that lives inside the Claw overlay drawer's bottom area. Owns the entry, attachments, autocomplete, history navigation, Ctrl+V paste, and the four inline status toggles (`claw`, `sleep`, `pin`, `web_search`).

## Key Features

- **Embedded-in-drawer by design.** The old floating-over-cursor mode is gone; the bar always lives inside `TerminalOverlay`. `set_embedded(true)` disables the bar's self-hide on Enter/Escape so the drawer owns visibility. `is_active` stays latched while embedded — code outside this module (e.g. `TerminalPaneComponent::grab_focus`) checks `claw_popover.is_visible()` instead.
- **Auto-wrapping multi-line input & top attachment strip.** `AttachmentManager`'s `gtk::FlowBox` is placed in `msgbar_slot` directly above `.boxxy-msgbar` (hidden when empty so 0 attachments takes 0 height). When attachments are added via `Ctrl+V`, they render as compact pill tags (`Image ×`, `Text Snippet ×`) above the input bar. Inside `.boxxy-msgbar`, the left avatar button is anchored in a box with `valign: Start`, the `gtk::TextView` (`WrapMode::WordChar`) expands across the full width, and trailing warning-colored status icons (`sleep_indicator` and `vibe_indicator`) sit at the right end of the input box (Discord-style) when Sleep Mode or Vibe Mode is active.
- **Enter-to-send (no external send button).** Submitting text is purely keyboard-driven via `Enter` (while `Shift+Enter` inserts a newline), keeping the input bar spanning the full width of the drawer.
- **Dynamic Theming.** Styled by `crates/themes/build.rs` via the `.boxxy-msgbar` CSS class; inherits the active terminal palette's surface + foreground. Inside `.claw-drawer`, `resources/style.css` overrides the outer bar to be a rounded pill while the entry is transparent — giving the bar the field-shape and the send button zero chrome.
- **Unified Status Indicator.** The bot icon on the far left is both the Claw toggle and a real-time status monitor. Driven by `set_status(AgentStatus)`: Active / Sleep / Error / Off states map to the `status-active` / `status-sleep` / `status-error` CSS classes on the claw + sleep buttons.
- **Native Autocompletion.** `AutocompleteController` from `boxxy-core-widgets` with six providers:
  - `FileCompletionProvider` — `@<file-or-dir>` — non-blocking background workspace indexer (`file_index.rs`) powered by `ignore 0.4.34` (`WalkBuilder` respecting `.gitignore` and `BLACKLIST.md`) and `frizbee 0.13.0` (SIMD Smith-Waterman fuzzy matcher), with OpenCode-style frecency boosting (`file_frecency.jsonl`), `Tab`/`Enter` directory drilling (`@crates/window/`), `#start-end` / `:start-end` line-range preservation, and outside-CWD traversal (`../`, `~/`, `/`).
  - `AgentCompletionProvider` — `:<character-name>` — fetches characters from `CHARACTER_CACHE` and live status from `CLAIMS_CACHE`.
  - `DebateCompletionProvider` & `DramaCompletionProvider` — `/debate <:character>` and `/drama <:character>` — lists peer characters (excluding the pane's current Host character) with avatars, colors, and Swarm status ("Active Peer (Swarm)" vs "Available Guest").
- **CommandCompletionProvider** — `/resume` ("Resume a past conversation"), `/debate` ("Start a multi-character debate or chat"), `/drama` ("Toggle Visual Novel mode"), `/stop` ("Stop an ongoing multi-character debate"), `/undo` ("Revert file edits from the last turn"), `/models` ("Switch model"), `/vibe` ("Enable Vibe Mode (auto-run safe tasks)" / "Disable Vibe Mode"), `/sleep` ("Put character to sleep" / "Wake character from sleep"), `/pin` ("Pin conversation" / "Unpin conversation"), `/web` ("Enable web search" / "Disable web search"), `/clear` ("Clear conversation history"), and `/exit` ("Withdraw character from terminal") — rendered with aligned command names and dim subtitle descriptions, automatically disabling session-bound commands when no character is attached.
  - `ResumeCompletionProvider` — `/resume <session>` — reads from an in-memory session cache refreshed asynchronously in the background (pre-warmed on `/` and refreshed with a 2s TTL) so `get_completions` never blocks the GTK main thread. Shows LLM-generated titles, agent-colored badges, relative timestamps (`10h`, `2d`); pinned sessions float to the top.
- **Avatar Popover Toggles.** Clicking the left-hand user avatar (`claw_toggle`) opens a compact popover above the avatar containing `sleep_toggle`, `pin_toggle`, `web_search_toggle`, and `vibe_toggle`. Each fires the caller-supplied callback; per-pane state (`is_pinned`, `is_web_search`, `is_vibe`, `session_status`) is held on `TerminalPaneComponent` and synced back via `update_ui(status, pinned, web_search, vibe)`.
- **Persistent History.** `MsgHistory` loads asynchronously from `boxxy-db` (SQLite) via an explicit `HistoryState` state machine (`Uninitialized`, `Loading`, `Ready`, `Failed`) that merges any `pending_writes` submitted while loading. Capped at ~100 entries in memory, images pruned after 20 — keeps RAM flat even after thousands of sessions.

## Query Submission Flow
On Enter: build payload via `AttachmentManager::build_payload(entry_text)` → get `(text, Vec<base64_image>)` → push into `MsgHistory` → fire the caller's `on_submit` callback. The caller (pane code) wraps that as `ClawMessage::ClawQuery { query, snapshot, cwd, image_attachments }` and sends it via the agent channel. In embedded mode the bar does not self-hide — the drawer stays open through the agent's thinking phase so the user can follow up without reopening.

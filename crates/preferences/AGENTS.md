# Preferences Crate (`boxxy-preferences`)

## Responsibility
Manages application settings, persistence, and the Preferences UI. This crate ensures that user configurations (font, theme, API keys, etc.) are atomically persisted to disk and synchronized across all windows and the background daemon.

## Architecture
The crate uses a declarative UI paired with lock-free RCU state updates:

- **`config.rs`**: Defines `Settings` (including mandatory default `claw_model`, per-character `character_models`, and system-wide `memory_model` plus `resolve_character_model`, `effective_memory_model`, and `default_model_broken_reason`) and `AppState`, default values, environment API key resolution (`boxxy_sys_utils::env::PROVIDER_ENV_KEY_MAP` + custom `api_key_env`), Vibe Mode directory validation (`validate_vibe_trusted_dir`), and atomic JSON persistence (`~/.config/boxxy-terminal/settings.json` and `state.json`).
- **`component.rs`**: Implements `PreferencesComponent` using an **`AdwNavigationSplitView`** architecture with a declarative 12-category navigation table, unified `sync_settings(&Settings)` hooks across all pages, and zero-allocation pre-indexed search filtering.
- **`ui_utils.rs`**: Shared internal UI primitives: `Debouncer` (coalescing rapid text/slider edits with immediate flush on `Enter`, focus-out, or unmap), `bind_mapped_poller` (single-instance timers active strictly while a page is mapped), `SearchRow`, `SubpageHeader` (shared `< APIs` / `< MCP` back-button and `AdwWindowTitle` controller for category subpages), portal-safe `open_directory` (`GtkFileLauncher`) / `open_uri` (`GtkUriLauncher`), and `make_editable_color_dot` backed by `boxxy_themes::ColorDot` (zero global `GtkCssProvider` registrations).
- **`resources/ui/preferences.ui`**: The widget tree is defined in this GtkBuilder XML file and loaded from GResources at runtime.

## Key Features
- **Categorized Navigation**: Settings are grouped into Terminal (Appearance, Terminal, Cursor, Layout — including the 3-way `AdwToggleGroup` `Display Move Handle` control for `pane_move_handle: PaneMoveHandleMode { Always, SplitPanesOnly, Never }`, defaulting to `SplitPanesOnly` — and Previews), Themes (Boxxy Official Themes `Boxxy Dark` and `Boxxy Light`, Accent Color overrides, Community `.toml` Themes in `~/.config/boxxy-terminal/themes/`, and Legacy Adwaita Themes), APIs & Subscriptions, Characters, Desktop Integrations, MCP, Skills, Claw UI & Sounds, Toolbox & Permissions, Shortcuts, Advanced, and About (`enable_broadcasts` for Boxxy News notifications and `enable_telemetry` for anonymous telemetry) sections.
- **Real-Time Search**: A global search entry in the sidebar filters both categories and individual setting rows (including dynamic custom endpoints, MCP servers, Vibe folders, community themes, custom characters, and shortcut triggers) without per-keystroke heap allocations.
- **Dynamic API Support, OAuth Subscriptions, OpenAI-Compatible Endpoints & MCP Subpages**: The APIs section displays configured built-in catalog API-key providers inline (with debounced `PasswordEntryRow`s that preserve selected models while rotating keys) alongside an **Add Provider…** sub-page (`apis/catalog_provider_dialog.rs`), followed by a **Subscriptions** group (`apis/chatgpt_oauth.rs`) for interactive ChatGPT / Codex PKCE browser and device-code OAuth sign-in/sign-out, and an **OpenAI-Compatible Endpoints** group (`apis/openai_compat_dialog.rs`) with generation-guarded `/models` fetching, URL/name validation, and per-model context/thinking/cost overrides. Keys and OAuth status resolve from `api_keys`, `ENV_API_KEYS`, `boxxy-ai-core` OAuth status (`CHATGPT_OAUTH_SENTINEL`), or process environment variables (`PROVIDER_ENV_KEY_MAP` including `CHATGPT_ACCESS_TOKEN` and `TAVILY_API_KEY`). Similarly, the **MCP** section (`mcp/mod.rs`, `mcp/mcp_dialog.rs`) uses a `slide-left-right` `GtkStack` (`mcp_stack`) to open an inline **Add / Edit MCP Server** sub-page (`McpEditorPage`) with `< MCP` header navigation, `Escape` pop-back, and Stdio/HTTP validation.
- **Master Capability Switches & Vibe Mode Trusted Locations**: Settings like `enable_web_search` and `web_search_on_by_default` implement the "Master Switch vs Local Toggle" pattern. `Toolbox & Permissions` also configures `max_roundtable_turns` (`Character Chat Turn Limit`, default `20`, range `1..=100`) and `vibe_trusted_dirs` (`Vibe Mode Locations`), blocking `/`, system directories, bare `$HOME` and its ancestors (e.g. `/home`), sensitive credential directories (`~/.ssh`, `~/.gnupg`, `~/.aws`, `~/.kube`, `~/.pki`, `~/.local/share/keyrings`), and Boxxy's config directory.
- **Lock-Free Cache & Single-Broadcast Sync**: `Settings` is cached in `LazyLock<ArcSwap<Settings>>`. All UI pages mutate settings directly via `Settings::update(|s| ...)`, which skips no-op updates (`next == current`), serializes generation-stamped atomic temp-file writes (`settings.json.<pid>.<gen>.tmp`), and broadcasts once on `SETTINGS_EVENT_BUS` after the rename completes. External asset updates (`.toml` community theme hot-reloads or user `AVATAR.png` changes) emit `Settings::notify_changed()`.
- **Background Process Persistence**: The `Always Keep Running Processes in Background` switch in Advanced → Shell corresponds to `pty_persistence: bool` (default `false`), detaching active shells and AI sessions into `boxxy-agent` on tab/window close without prompting.
- **Desktop Integrations**: `integrations/mod.rs` groups GNOME and COSMIC companions. `nautilus_integration: bool` (default `true`) installs or removes `open_with_boxxy.py` under `$XDG_DATA_HOME/nautilus-python/extensions/` (falling back to `~/.local/share/nautilus-python/extensions/`).
- **Non-Blocking Filesystem Polling (`themes_page`, `skills`, `characters`)**: Directory scans (`discover_community_themes`, `discover_skill_summaries`, character catalog/avatar I/O) run off the GTK main thread via `spawn_blocking` and poll strictly while their respective page is mapped on screen.
- **Claw UI & Shortcuts**: `claw_ui/mod.rs` manages `overlay_bottom_gap`, `always_show_code_blocks`, `enable_tips`, `overlay_font_scale` (`60%..=220%`), `currency` (`USD`, `EUR`, `CNY`, `INR`, `BRL`), sound/badge toggles, and a live `Ask Boxxy-Claw` shortcut row synced with `boxxy-keybindings`. `shortcuts/` (`mod.rs`, `capture_dialog.rs`, `override_popover.rs`, `resources/ui/shortcut_capture_dialog.ui`) provides interactive click-to-record shortcut customization backed by `~/.config/boxxy-terminal/keybindings.toml`, 1-click per-row revert, multi-chord triggers, `performable:` Smart Shortcut toggles, `Edit keybindings.toml` / `Reset All` controls, and single-line graphical override badges (`[⚡]`) with interactive `GtkPopover` override maps.

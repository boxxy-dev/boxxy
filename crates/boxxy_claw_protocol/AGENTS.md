# Claw Protocol Crate (`boxxy-claw-protocol`)

## Role

Shared, GTK-free, engine-free DTO layer used across the UI ↔ daemon D-Bus boundary. Anything the UI and the reasoning engine need to agree on lives here; anything heavier does not.

The crate is the single shared contract between the UI process and the daemon process, organized into focused domain submodules with a thin re-exporting `lib.rs` facade. `rig` is strictly opt-in behind the `rig` Cargo feature (enabled only by `boxxy-claw`) so pure UI and CLI consumers compile without LLM SDK dependencies.

## Module Layout & Contents

- **`messages.rs` (`ClawMessage` & `ClawEngineEvent`)**:
  - **`ClawMessage`**: every request the UI can send down to an active `ClawSession`. Includes `Initialize`, `Deactivate`, `Reload`, `ClawQuery`, `UserMessage`, approval replies (`FileWriteReply`, `KillProcessReply`, …), sleep/pin/web-search/vibe toggles, delegated-task plumbing, correlation-ID replies (`ScrollbackReply`, `SpawnAgentReply`), and `SettingsInvalidated` for cross-process settings sync.
  - **`ClawEngineEvent`**: every event the engine emits upward — `AgentThinking`, `TurnTraceProgress`, `AssistantTextDelta`, `DiagnosisComplete`, proposal events (`ProposeFileWrite`, `ProposeKillProcess`, …), `Identity`, `PinStatusChanged`, `RequestScrollback`, `RestoreHistory`, `LongTaskCompleted`, `PushGlobalNotification`, etc., plus zero-copy `character_id()` / `agent_name()` attribution accessors. `RequestScrollback` uses a `request_id` with a matching `ClawMessage::ScrollbackReply` so no `oneshot::Sender` ever crosses the IPC boundary.
- **`rows.rs` & `trace/` (`mod.rs`, `tool_summary.rs`, `coalesce.rs` — `PersistentClawRow` & `TurnTraceItem`)**: the row variants the sidebar/overlay render and the DB stores (`User`, `Diagnosis`, `Suggested`, `ToolCall`, `ProcessList`, `SystemMessage`, `Command`, `FileDiff`) with zero-copy accessors (`pane_id`, `agent_name`, `character_id`, `trace`, `usage`). `Diagnosis` and `Suggested` carry `trace: Vec<TurnTraceItem>` (`Thought`, `Tool`, `Edit`, `Skill`) summarized via single-allocation `ActivitySummary` (`+ 4 commands, 19 edits, 8 thoughts, 2 reads, 1 tool`), `extract_reasoning_summary` / `live_reasoning_title` (zero-copy bold-title parsing supporting glob `*` patterns & `[REDACTED]` stripping), `busy_tool_label` (including `generate_image` prompt/generation progress), single-pass JSON tool-result summarization (`tool_result_to_trace_item` with zero-clone stream clipping), and speaker-aware `coalesce_restored_history` (folding legacy DB tool/diff rows into turn traces on `/resume` and pruning rejected file-write proposals).
- **`diff/` (`mod.rs`, `compute.rs` — `FileDiff`)**: local diff engine and serialisable DTOs (`FileDiff`, `DiffKind`, `DiffStats`, `DiffHunk`, `DiffPairRow`, `DiffCell`, `DiffSpan`) powered by `similar 3.2.1` (`Algorithm::Histogram` + word-level inline changes with `semantic_cleanup`). Bounds file sizes (`<= 2 MiB`) on both created and modified files, caps rendered rows (`MAX_DIFF_RENDER_ROWS = 250`) and per-line character counts (`MAX_DIFF_LINE_CHARS = 4,096`), handles created (`DiffKind::Created`) and binary (`DiffKind::Binary`) files, and generates `git apply`-compatible unified patches (`to_unified_patch` with emitted-row hunk headers).
- **`status.rs` (`AgentStatus`, `ContextQuality`, `TriggerSource`, `TransitionRequest`, `SpawnLocation`, `ClawEvent`)**: live agent FSM states (`{Off, Sleep, Waiting, Working, Locking{resource}, Faulted{reason}}`) with `is_enabled()` / `is_busy()` predicates, pane spawn placements, and inter-agent pub/sub event payloads.
- **`tasks.rs` (`ScheduledTask`, `TaskType`, `TaskStatus`, `IntervalPhase`, `IntervalSchedule`, `PendingTaskInfo`)**: scheduled-reminders and multi-round interval timer payloads with checked, overflow-safe `toggle_pause_at`, plus the cross-agent `PendingTaskInfo` snapshot shape.
- **`usage.rs` (`UsageWrapper`, `SessionUsage`, `format_number_with_commas`, `format_usd`)**:
  - **`UsageWrapper`**: serde-safe DTO wrapper (`from_raw` plus optional `#[cfg(feature = "rig")] From<rig::completion::Usage>`) with saturated `total_tokens()` and `effective_context_tokens()`.
  - **`SessionUsage`**: `Copy` session-level context and cost state (`{context_tokens, context_window, total_tokens, cost_usd, tools_used}`) with NaN-hardened `record_turn()`, `context_percent()`, and stack-buffered `format_number_with_commas` / `format_usd`.
- **`environment.rs` (`ClawEnvironment` & `ProcessSample`)**: the async trait the reasoning engine calls for privileged host operations (`exec_shell`, `read_file`, `list_processes` returning `Vec<ProcessSample>`, `get_clipboard`, …). Implemented in-process on the daemon (`boxxy_agent::claw::ClawSubsystem`) and forwarded over D-Bus by `boxxy_terminal::agent_manager::DbusClawEnvironment`.
- **`characters/` (`mod.rs`, `cache.rs` — Character claim types & coherent caches)**:
  - `HolderKind { Pane = 0 }` (`#[repr(u8)]`) — extensible holder discriminator.
  - `CharacterClaim { holder_id, holder_kind, character_id, session_id, petname, owner_bus_name }` — one live claim (`petname` is the stable two-word Red Pony swarm address; `owner_bus_name` drives `NameOwnerChanged` crash cleanup).
  - `RegistrySnapshot { catalog, claims, revision }`, `ClaimedSession`, `ClaimError` (`Display` + `Error`), `StartupToken`, `PeerQuery`, `PeerInfo`.
  - `CHARACTER_CACHE: ArcSwap<Vec<CharacterInfo>>`, `CLAIMS_CACHE: ArcSwap<Vec<CharacterClaim>>`, and an internal coherent `CoherentState` `ArcSwap` (`load_coherent_registry`) with no-op snapshot deduplication and a monotonic watch generation counter (`subscribe_registry_changes`) so availability helpers and `/resume` caches never observe torn states or miss `revision == 0` / daemon-restart transitions, plus Unicode-aware case-insensitive `find_character_exact` / `resolve_character` and `MCP_STATUS_CACHE`.
- **`character_loader/` (`mod.rs`, `bundled.rs`, `toml_patch.rs`)**: `sync_data`-hardened atomic disk I/O (`atomic_write` via hidden `.tmp` rename), multi-line-safe in-place `CHARACTER.toml` patching (`save_character_color`, empty/missing/duplicate/reserved-incognito UUID repair), `d_type`-accelerated `load_characters` / `load_characters_in`, symlink-safe `reset_to_defaults_in`, and declarative `BUNDLED_CHARACTERS` extraction (`niko-una`, `levi-kujo`, `kuro`, plus `inco-gnito` avatar).
- **`slash.rs` (`SlashCommand` & `SlashSubmitEffect`)**: canonical slash-command parser (`SlashCommand::parse`, immune to Unix `/etc/...` filesystem paths), autocomplete auto-submit predicate (`auto_submits_on_complete`), and submission state classifier (`classify_submit_effect` -> `{FrontendOnly, InstantControl, CancelAndSettle, StartsTurn}`) shared between `boxxy-claw-widget` (`TerminalOverlay`, `MsgBarComponent`), `boxxy-terminal`, and `boxxy-claw` so slash commands never echo raw `/command` text into conversation or mis-trigger `OverlayState::Thinking`.
- **`skill_loader.rs` & `str_utils.rs`**: unified UTF-8 BOM- and boundary-safe YAML frontmatter parser (`parse_frontmatter_block`, `parse_skill_document`), stack-buffered 4 KiB header scanner (`read_skill_summary`, `d_type`-fast `discover_skill_summaries`), slug deduplication, `is_skill_disabled`, and shared zero-allocation Unicode case-insensitive / scalar-truncation utilities (`str_utils.rs`).

## Design Rules

- **No GTK types.** This crate compiles without `gtk4`/`libadwaita`. The UI-side wrappers live in `boxxy-claw-ui`.
- **No mandatory `rig` or `boxxy-claw` reasoning-engine dependencies.** `boxxy-claw` depends on this crate (enabling the optional `rig` feature for `From<rig::completion::Usage>`), never the reverse.
- **All public DTOs implement `Serialize + Deserialize`**, even the large enums. IPC transport uses JSON; the types are wire-format-agnostic.
- **Correlation IDs over channels.** When the engine needs a response from the UI (scrollback, spawn-agent, delegated-task reply), the request carries a `uuid::Uuid` request ID and the reply is a distinct `ClawMessage` variant with the same ID. No `Sender<T>` ever crosses a process boundary.

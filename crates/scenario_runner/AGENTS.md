# Scenario Runner (`scenario-runner`) — Deterministic Headless E2E Harness

## Overview

`scenario-runner` is Boxxy's GTK-free, deterministic End-to-End (E2E) workflow test harness (`crates/scenario_runner`). Instead of relying on live external LLM API keys or untyped YAML fixtures, it drives the **real** headless Boxxy stack in standard `cargo test` runs:
- Real `ClawSession` actors (`boxxy-claw`), `rig 0.47` streaming + tool concurrency, and `WorkspaceRegistry`
- Real `ClawSubsystem` (`boxxy-agent`) sharing a single `AgentState` with `PtyRegistry`
- Real `boxxy-db` SQLite WAL + FTS5 persistence inside a process-isolated `TempDir` config root
- Real Linux POSIX PTYs (`/bin/bash` + `OSC 7` / `OSC 133` shell integration + 4 MB detached `RingBuffer`)
- Headless `boxxy-cli` `+doctor` and `+env` verification

## Architecture & Modules

- **`src/config_env.rs`**: Bootstraps a process-scoped temporary config root via `boxxy_sys_utils::configure_dev_options(CliDevOverrides { dev: true, instance: Some("e2e"), ephemeral: true, config_dir: Some(...), debug_context: env_truthy("BOXXY_DEBUG_CONTEXT"), .. })`, initializes single-init `env_logger` (honoring `BOXXY_DEBUG_CONTEXT=1 RUST_LOG=model-context=info`), disables telemetry, self-updates, and ambient network fetches (`enable_os_context = false`), seeds bundled Characters v2 packages (`load_characters`), and wires `Settings` to local `OpenAiCompatible` endpoints (`mock-claw-model` + `mock-memory-model`). Never touches `~/.config/boxxy-terminal/`.
- **`src/mock_llm.rs` (`MockLlmServer`, `MockStep`, `MockToolCall`, `TurnGate`, `RecordedChatRequest`)**: In-process `tokio::net::TcpListener` (`127.0.0.1:0`) OpenAI `/v1/chat/completions` HTTP/SSE server. Parses multi-kilobyte request bodies (`Content-Length` up to 4 MiB), exposes `system_prompt_text()` and `conversation_text()` inspectors across string and array content blocks, isolates background `mock-memory-model` calls (Turn-1 session title generator, `flush_history`, `DreamOrchestrator::run_cycle`) and `/btw` side-channel calls (`tool_choice == "none"`) from main conversation turns, streams spec-compliant SSE `reasoning_content`, `tool_calls`, `content`, and `usage` chunks, supports request-inspecting `MockStep::dynamic` steps for runtime-minted correlation IDs (`delegate_task_async` -> `await_tasks`), and provides zero-sleep `TurnGate` barriers for deterministic mid-turn concurrency tests.
- **`src/pane_driver.rs` (`PaneDriver`, `CompanionPane`, `CompanionTable`)**: Non-dropping event collector (`Arc<Mutex<Vec<ClawEngineEvent>>>` + `tokio::sync::Notify`) with a monotonic read cursor so sequential `wait_for_next` assertions never drop interleaved events or re-match stale turns. Handles correlation-ID side effects (`RequestSpawnAgent`, `RequestScrollback`, `InjectKeystrokes`, `RequestCloseAgent`, and companion-pane `ProposeTerminalCommand`).
- **`src/pty_driver.rs` (`PtyShellSession`)**: Real POSIX pseudoterminal (`posix_openpt` / `grantpt` / `unlockpt` / `ptsname_r`) + `/bin/bash` child running with a synthetic `HOME` (never sourcing host `~/.bashrc`) and Boxxy's `apply_shell_integration` scripts. Exercises `PtyRegistry::release_owner`, detached `RingBuffer` capture, `reattach`, deterministic `OSC 133;D` completion waiting + `[PROMPT]`/`[COMMAND]`/`[OUTPUT]` semantic snapshot parsing (`wait_for_osc133_done` / `semantic_snapshot_and_exits`), and process-group `SIGKILL` cleanup on `Drop`.
- **`src/harness.rs` (`TestWorkspace`)**: High-level test fixture combining `MockLlmServer`, shared `AgentState` (`ClawSubsystem` + `PtyRegistry`), `Db`, `WorkspaceRegistry::reset_all()` isolation, subdirectory & `/incognito` pane spawning (`spawn_pane_in_dir`, `spawn_incognito_pane`), temporary workspace files, synthetic `SKILL.md` installation (`write_skill`), Vibe Mode directory trust, and `BLACKLIST.md` configuration.
- **`src/main.rs`**: Standalone CLI smoke check (`cargo run -p scenario-runner`) verifying edit proposal, approval, `/undo`, and real PTY `OSC 133` round-trip in `< 200ms`.

## Automated Real User Workflow Suites (`tests/workflows.rs` & `tests/workflows/`)

Organized as modular submodules inside a single integration test binary (`tests/workflows.rs`) so Cargo links once while executing every workflow under `cargo test -p scenario-runner`:
1. **`tests/workflows/edit_and_undo.rs`**: `@file` Turn-1 hash pre-loading, `replace_in_file` diff proposals, zero-token user rejection (`ProposalResolved { approved: false }`) with same-pane Turn-2 `@file` & rejection-note continuity, mid-proposal user steering with `@file` preload, approval `TurnTraceItem::Edit`, and `/undo` byte-exact file restoration.
2. **`tests/workflows/error_diagnosis.rs`**: Origin-aware terminal error diagnosis — ignores benign exit codes (`grep` 1, `SIGINT` 130), emits `LazyErrorIndicator` at **0 LLM tokens** on user-typed errors until `RequestLazyDiagnosis`, auto-diagnoses agent-originated command failures, and verifies `InjectCommand` rejection (`CancelPending`) spends 0 extra tokens, clears `pending_inject_command`, and records `[Proposed command ... — rejected by the user]` in history.
3. **`tests/workflows/queue_btw_and_abort.rs`**: In-flight `TurnGate` synchronization, FIFO follow-up prompt queueing (`QueueUpdated`), draft recall (`QueuedPromptRecalled`), concurrent & idle `/btw` side-channel (`ForbidToolsHook` blocking rogue tool calls, warm `in_flight_snapshot` reuse with settled `Thinking…` status reset, live changed `Terminal Snapshot` + `CWD` on idle populated sessions without `last_snapshot_hash` mutation, zero `claw_events` mutation), and `Abort` (`Esc Esc`) queue parking + `[Previous task was interrupted by the user]` alternation bridging.
4. **`tests/workflows/persistence_and_resume.rs`**: Multi-tool turn trace & catalog-priced token persistence in `boxxy-db`, Turn-1 background session title generation, visual-only `/clear` (`SoftClearHistory`), and cross-pane `/resume` onto a pre-used pane with character switch (`Character Switch: Niko Una → Levi Kujo`), `Evicted`, coalesced `RestoreHistory`, clean `/undo` & `read_file_hashes` & `last_snapshot_hash` isolation, and post-resume follow-up turn perspective-flipping.
5. **`tests/workflows/companion_panes_and_vibe.rs`**: `1 Home Pane + Companion Terminal` (`spawn_agent` -> `pane-2` -> `terminal_exec` -> `read_pane_buffer` -> `send_keystrokes_to_pane` -> `close_agent`) and Vibe Mode ("Scoped YOLO") guardrails (trusted workspace auto-approve vs out-of-workspace manual approval fallback vs `BLACKLIST.md` hard block).
6. **`tests/workflows/pty_and_cli.rs`**: Real PTY + `/bin/bash` `OSC 7` / `OSC 133` markers, `PtyRegistry` detach + 4 MB `RingBuffer` replay + `reattach`, and isolated `--dev --ephemeral --instance=e2e` headless `boxxy-cli` `+doctor --json` & `+env` execution.
7. **`tests/workflows/context_hygiene_and_compaction.rs`**: Static system prompt & compact turn-context formatting, canonical Host `Agent Name` + `Pane Alias` / `Swarm Petname` identity injection, `[TERMINAL_SNAPSHOT: EMPTY]` & `[TERMINAL_SNAPSHOT: NO_CHANGE]` deduplication, settled `sessions.history_json` persistence without transient turn bloat, unified `@file` `<config_dir>/auth` blacklist enforcement, `EXTERNALLY MODIFIED FILES NOTICE`, fence-safe `--- ATTACHMENTS ---` retention + 4-turn freshness stripping (`TRANSCRIPT_CLIP` + `[stale attachment output clipped]`), and `>= 75%` `input_limit` exchange-boundary compaction (`[SESSION_CHECKPOINT]` + `DemotionExtractor` `flush_history` attachment stripping).
8. **`tests/workflows/incognito_and_roundtable.rs`**: `/incognito` (`Inco Gnito`) zero-tool, zero-context, zero-DB guarantee and multi-character `/debate :levi-kujo` perspective-flipping (`[Character Niko Una said]:` with zero persona bleed, canonical Host overlay attribution, and deduplicated autonomous-round instructions) + autonomous turn-limit termination.
9. **`tests/workflows/skills_and_memories.rs`**: Synchronous Turn-1 `SkillRegistry` FTS5 indexing (`--- ACTIVE SKILLS ---` top-1 full injection, word-boundary trigger matching against substring collisions, compact `--- AVAILABLE SKILLS ---` Toolbox, `Settings.disabled_skills` exclusion, `TurnTraceItem::Skill`), on-demand `activate_skill`, `memory_store`, and multi-tier memory recall (`PINNED`, `SYSTEM ENVIRONMENT`, `RELEVANT PREFERENCES & FACTS`, and `[PROVISIONAL]` candidates).
10. **`tests/workflows/sleep_and_multimodal.rs`**: `SleepToggle` lifecycle history flush (`flushed_watermark`), 0-token error suppression while sleeping, Hard Wake (`[WHILE_YOU_SLEPT]` + `WHILE_YOU_SLEPT_ACK` command delta), cursor-ordered `[Text, Image, Text, Image]` multimodal wire serialization without Turn-2 base64 re-sends, and zero-tool / zero-skill `Read What's New` (`--- UPDATE CHANGELOG CONTEXT ---`) execution with settled `sessions.history_json` hygiene and Turn-2 follow-up changelog retention.
11. **`tests/workflows/swarm_locks_and_promises.rs`**: `GLOBAL RADAR` peer discovery, `LockTable` contention (`acquire_lock` / `release_lock`), cross-pane `delegate_task` (`DelegatedTask` -> `DelegatedTaskReply`), and `EventBus` `subscribe_to_pane(event_type="output_match")` autonomous sleep + regex wake-up.
12. **`tests/workflows/hotswap_dreaming_and_handoff.rs`**: Per-character model overrides (`Settings.character_models`), live mid-session model hot-swapping (`SettingsInvalidated` + `ToggleWebSearch`) and `ForegroundProcessChanged` `--- TUI WARNING ---` modality, 1-turn collaborative `invite_character(..., debate=false)` handoff with `SWARM PEER BRIDGE` live home-pane snapshot bridging, async Map-Reduce (`delegate_task_async` + `await_tasks`), active-skill capability routing (`request_assistance`), multi-round interval task scheduling (`schedule_task` + `TogglePauseTask` + `CancelTask`), and end-to-end 3-phase `DreamOrchestrator::run_cycle()` (`EXISTING VERIFIED MEMORIES` conflict resolution, `preference` tier protection, and `MEMORY.md` / `DREAMS.md` audit output).

14. **`tests/workflows/osc133_and_workspace_scoping.rs`**: Real `/bin/bash` PTY `OSC 133` semantic snapshot pipeline (`[PROMPT]` / `[COMMAND]` / `[OUTPUT]` preservation with 4-backtick outer snapshot fences, multi-command scrollback `grep` exit-1 filtering ignoring trailing empty prompts, `InjectCommand` preservation of explanatory `rust` blocks, and `Sleep` `[COMMAND]` delta extraction) plus hierarchical workspace memory/interaction scoping (subdirectory inheritance vs sibling/cross-project isolation) and `GLOBAL RADAR` `last_command` attachment-leak immunity.
15. **`tests/workflows/interactive_handoff_and_drama.rs`**: Interactive `terminal_exec` foreground TUI handoff (`ForegroundProcessChanged` urgent routing + `TerminalCommandAccepted` follow-up queuing + `CompleteRunningTerminalCommand` 0-token handoff & queue parking), RAII `InFlightClearGuard` cleanup across `/stop` aborts before idle `/btw` queries, nested 4-backtick code fence isolation against false `@file` preloads and `:character` roundtable triggers, and Visual Novel `/drama` (`typewriter: true`) mid-roundtable `Abort` + user interjection resumption.

18. **`tests/workflows/multithread_salvage_wake_llm_and_ipc_creds.rs`**: Real multi-threaded Tokio (`flavor = "multi_thread", worker_threads = 2`) mid-turn `Abort` salvage racing against `InFlightClearGuard::drop`, `SendQueuedPrompt` unparking with fresh terminal snapshots, immunity against hoisting duplicate `--- REFERENCED FILES ---` / `--- UPDATE CHANGELOG CONTEXT ---` blocks out of `BOXXY_DEBUG_CONTEXT` terminal snapshots, IPC-only `AgentState.api_keys` propagation across parallel read-only tool batches (`file_read` + `grep_search` + `glob_search`), Turn-1 title generation, `Sleep` `flush_history`, and `> 3`-command LLM Dreamer wake summarization (`summarize_wake_delta`), plus HTTP 429 error recovery parking queued follow-up prompts.

## Running Tests

```bash
# Run all deterministic E2E workflow suites
cargo test -p scenario-runner

# Run the standalone smoke check binary
cargo run -p scenario-runner
```

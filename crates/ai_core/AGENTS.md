# boxxy-ai-core Agents & Architecture

## Responsibilities
Provides Boxxy's unified AI provider abstraction, native ChatGPT / Codex OAuth subscription authentication, catalog/cost resolution, native server-side web search helpers, and `BoxxyAgent` runtime on top of `rig-core` (`0.47`, with `default-features = false, features = ["reqwest", "agent", "rustls"]`). Abstracts ChatGPT (`chatgpt` Codex OAuth subscription), Gemini, Anthropic, OpenAI, DeepSeek, Moonshot, xAI, Z.ai, Mistral, MiniMax, Groq, OpenCode Zen (`opencode`), OpenCode Go (`opencode-go`), OpenRouter, Ollama, and custom `OpenAiCompatible` endpoints (LiteLLM, vLLM, llama.cpp) behind a single cohesive API.

## Architecture & Modules
Organized into focused submodules re-exported from `src/lib.rs`:

- **`credentials.rs` (`AiCredentials`)**: Carries provider API keys, the Ollama base URL, and configured `OpenAiCompatibleEndpoint` entries (`with_custom_endpoints`). Resolves trimmed API keys without heap cloning when present in `api_keys`, falls back to `boxxy_sys_utils::env::PROVIDER_ENV_KEY_MAP` environment variables (or `endpoint.api_key_env`), strips optional trailing `/v1` on `ollama_url`, and preserves `OllamaConfig`'s default `http://localhost:11434` URL when `ollama_url` is blank.
- **`chatgpt_auth.rs` (`ChatGptAuthStatus`, `sign_in_chatgpt_oauth`, `sign_out_chatgpt_oauth`, `refresh_chatgpt_account_models`)**: Manages native ChatGPT / Codex subscription OAuth via `rig::providers::chatgpt::auth::Authenticator` and `FileTokenStore` (`<config_dir>/auth/chatgpt.json` + cross-process `flock` `chatgpt.lock`), supporting PKCE browser sign-in (`127.0.0.1:1455`/`1457`) with automatic device-code fallback, RFC 7009 token revocation on sign-out, lock-free `ArcSwap` status/JWT-claim caching (`CHATGPT_OAUTH_SENTINEL`), live account model discovery (`rig::client::chatgpt_models::account_models`), and dynamic `ModelSpec` synthesis (`build_chatgpt_model_spec`).
- **`catalog.rs`**: `resolve_catalog_spec`, `model_context_window` / `model_context_window_with_endpoints`, `model_input_limit` / `model_input_limit_with_endpoints` (`ModelSpec::input_limit()`), `model_output_limit` / `model_output_limit_with_endpoints` (`ModelSpec::output_limit()`), `enrich_usage_with_catalog_cost` / `enrich_usage_with_endpoints_cost` (3-tier cost resolution with `NaN`/negative rate sanitization and explicit `$0.00` clearing for local `Ollama`, flat-rate subscriptions `ChatGpt` & `OpenCodeGo`, and `zero_cost` custom endpoints), and `extract_response_context_tokens` (scanning `completion_calls.iter().rev()` for the latest non-zero window without mistaking multi-step cumulative totals for single-call context occupancy).
- **`reasoning.rs`**: `map_thinking_level`, `resolve_model_reasoning` / `resolve_model_reasoning_with_endpoints`, and `recommended_max_tokens_for_reasoning`. Honors custom endpoint `thinking_levels` overrides and `ModelSpec.reasoning`, maps `ThinkingLevel::XHigh` cleanly onto both `Effort::XHigh` and `Effort::Max`, clamps budget-based thinking strictly below `ModelSpec::output_limit()` while recommending safe `max_tokens` headroom for Anthropic/gateway dialects, and suppresses `Reasoning::Off` when `can_disable == Some(false)`.
- **`providers.rs`**: `ProviderModelBackend` (`Static(DynModel<Completion>)` vs `SignedIn(ErasedHandler)` over `SignedInModel` + `AgentBuilder::over_handlers`), `build_provider_model` / `build_provider_model_with_options` (`BuiltProviderModel`), `configure_agent_builder`, `needs_relaxed_finish_reasons`, and `fetch_openai_compatible_models`. Normalizes model slugs and endpoint URLs, connects OpenCode Zen/Go through `Catalog::builtin().connect_with(...)`, sets `Responses::with_store(false)` and omits caching when `stateless = true` (`/incognito`), attaches session `cache_key` (`prompt_cache_key` / `session-id` / `x-opencode-session`, with `CacheRetention::Long` on ChatGPT) and `OpenAiOptions::reasoning_summary(ReasoningSummary::Auto)`, scopes `accept_unknown_finish_reasons` strictly to custom/gateway/local providers, and enables `done_without_finish_reason = true` on custom endpoints.
- **`search.rs`**: `native_search_provider_tool`, `native_search_additional_params`, `attach_native_search`, `collect_url_citations`, `append_citations_to_output`, and `extract_native_search_summary`. Enforces `http://`/`https://` scheme validation, escapes CommonMark brackets/parentheses on citation links, and extracts server-side search queries across OpenAI, Anthropic, and Gemini (`GOOGLE_SEARCH_*` `toolCall`s).
- **`hook.rs` (`ModelContextHook`)**: Zero-overhead `rig::agent::AgentHook` for `--debug-context` / `BOXXY_DEBUG_CONTEXT=1` (`model-context` log target). Formats synchronously from borrowed slices strictly when enabled, incurring **zero** history, prompt, or string clones during standard runs.
- **`agent.rs` (`BoxxyAgent`, `AgentOptions`, `create_agent`, `create_agent_with_options`, `create_agent_with_config`)**: `Arc`-backed (`O(1)` clone) agent wrapper attaching `ModelContextHook` once at build time, with trailing-delta flushing and retry buffer reset in `chat_streaming`.
